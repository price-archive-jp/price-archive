## このリポジトリについて

`uniqlo_sale/publish_site.py` が生成した**静的サイトの生成物だけ**を置いています。
CSV・JSONの元データ、スクレイピングのコード、画像・商品説明・レビューは含みません。
`gh-pages` ブランチがそのまま GitHub Pages で配信されています。

- 商品ページは `noindex`、一覧・日別・コレクションのみ検索対象です
- 価格は観測時点の掲載価格で、現在の販売価格ではありません
- 最新の価格・在庫は公式サイトをご確認ください
